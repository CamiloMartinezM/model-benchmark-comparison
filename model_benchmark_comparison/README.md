# Published outputs

These files contain the September 6, 2026 comparison: 678 observations and 11 models in the default six-panel figure.

Open `model_benchmarks.xlsx` to inspect or edit the input. Open `model_benchmark_analysis.xlsx` for derived efficiency measures. Download `model_benchmark_comparison.html` and open it in a browser for interactive filtering and hover details.

Run the [standalone script](../model_benchmark_comparison.py) from the repository root to refresh the figures and derived analysis. The script preserves the editable workbook. Use a fresh output directory to regenerate a workbook from the embedded snapshot.

The [main README](../README.md) contains installation commands, the file inventory, and interpretation guidance. The [methodology](../docs/methodology.md) explains cost units, missing values, effort labels, and source limitations.
